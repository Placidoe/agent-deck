Agent Deck · 桌面外观

少一些噪声，多一点自己的风格。

统一文字、按钮、选中态和角色身份。保持熟悉的工作流程，让颜色成为提示，而不是干扰。

三种外观，同一套工作流程

浅色

清楚的文字、柔和的灰阶与轻量边界。画布、菜单、弹窗同步适配。

深色

中性的深灰底色，让状态与主要动作突出，不用大面积高饱和色。

跟随系统 · 默认

离开设置后仍响应系统外观变化；手动指定明暗模式后不受系统变化影响。

按钮、导航、选中项、键盘焦点、菜单和画布高亮使用同一套颜色。浅色与深色文字强调分别适配，成功、阻塞、失败保留独立的语义颜色。图片和产物内容不会被反色。

在哪里切换

  1. 打开左下角「设置 → 外观」。
  2. 选择浅色、深色或跟随系统，再选择主题色。
  3. 立即生效，关闭再打开仍保留。

可用 Tab 聚焦、方向键切换。不需要重启或模型调用。偏好在 React 首次渲染前解析，避免先出现错误外观再切换。

统一身份设计

应用图标、侧栏和 Main Agent 共享可编辑的层叠卡片标识。研究、工程、架构、审核使用稳定的图形与克制的角色色；用户使用独立的圆形头像。中文和英文角色都能识别。

矢量图形不依赖远程图片或字体；应用图标由同一份 SVG 生成 1024px PNG。

这轮交互细节

  1. 移除标题栏无操作的图标与预览中的假按钮。
  2. 下拉菜单支持方向键、Home/End、输入查找、Escape；Tab 收起并正常移动焦点，跳过禁用项。
  3. 成果刷新有忙碌状态和完成反馈。
  4. 发布入口合并重复操作；反馈放在弹窗内。转换失败可重试，不再保留旧稿件。
  5. 发布弹窗支持焦点循环与 Escape；窄窗口保留底部操作栏，复选框不再被通用输入样式拉伸。

外观可以变，执行的事实不变。

切换主题不会修改模型、权限、工作区、DAG 或审批状态。这里的预览不会启动工作，也不会制造运行进度。外观存储在当前设备的应用资料中；受限浏览器无法保存时会明确提示。
