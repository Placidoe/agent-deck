这次是深色界面的强调色切换，不是浅色 / 深色模式切换。按钮、导航、选中项、键盘焦点、菜单和画布高亮使用同一套颜色。成功仍是绿色，阻塞仍是暖黄色，失败仍是红色。

在哪里切换

  1. 打开左下角「设置」。
  2. 在「外观 → 主题色」选择颜色。
  3. 立即生效，关闭再打开仍保留。

主题色选项可用 Tab 聚焦、方向键切换。不需要重启或模型调用。

新的身份设计

应用图标、侧栏和 Main Agent 共享可编辑的层叠卡片标识。研究、工程、架构、审核分别使用稳定的图形与克制的角色色；用户使用独立的圆形头像。中文和英文角色都能识别。

矢量图形不依赖远程图片或字体；应用图标由同一份 SVG 生成 1024px PNG。

外观可以变，执行的事实不变。

切换主题不会修改模型、权限、工作区、DAG 或审批状态。这里的预览不会启动工作，也不会制造运行进度。外观存储在当前设备的应用资料中；受限浏览器无法保存时会明确提示。
