PERSONAL AGENT / 个人时间

Agent 在工作。
你可以做自己的事。

把注意力还给人，不把等待变成另一份待办。

静一静

养神、静坐。没有课程、打卡或成绩。

动一动

走动、喝水，或熟悉的运动。自己决定节奏。

继续工作

准备下一件事、审阅交付、阅读成果。

不用管我

自由安排。不计时，不催普通工作更新。

怎么用

有 Agent Deck 工作在执行时，工作区底部出现一行入口。展开后选活动、自己的时长和提醒方式。可以收起面板、切换页面；回来点「我回来了 · 看变化」。只展示开始时那批工作，不悄悄把新任务加入跟踪。

工作仍在执行→人选择自己的活动→安静计时 / 自由离开→回来接住真实变化
时间到了不会停止 Agent，也不会催你结束休息。计时是人的安排，不是任务预计耗时。

提醒与安全边界

选择实际行为
等我回来再看（默认）普通就绪更新不发送系统通知。
就绪时提醒我计划 / 交付 / 集成就绪，完成或停止时请求无声系统通知；同类状态在本次个人时间内去重。
阻塞或授权仍提醒独立开关。提醒不等于批准；审批边界不变。
我回来了结束本次跟踪。显示开始前后完成节点、登记产物与当前待处理状态；新增产物不代表已验收。

系统提醒受 OS 权限、专注模式和休眠影响，不保证送达。应用需保持运行；退出应用结束个人时间。最小化或页面切换不结束跟踪。系统通知不包含任务内容或私有路径。

轻量实现，不再消耗一轮 Token

WaitingCompanion 只读本机任务账本的窄投影，最多跟踪 20 项工作。状态更新按秒合并读取，不加载会话或文件内容；秒级倒计时完全本地，不调用模型。内外部 Mission 引擎使用相同投影；独立外部会话暂不包含。

随手记和未开始笔记的草稿在当前窗口内保留，按记录和已保存版本隔离；切换页面或重新加载不会直接丢失。关闭应用前仍应点击「记下来 / 保存笔记」。不自动保存为执行需求，不自动开始下一项任务。

本功能没有健身课程、健康诊断、签到、排名或 ROI。后续可在用户确有需要时扩展，不用等待时长强迫人“有价值”。
