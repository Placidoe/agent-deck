PERSONAL AGENT · 第二阶段 / BETA · 2026-10-04

有来源的草稿，而不是凭空生成的结论

这一步，我先补上一个具体能力：让自有 Harness 读取你选定的资料，以及逐个批准的公开网页，生成 HTML 草稿。来源、产物和权限分开管理；你能看到它读过什么，再决定是否验收。

实际状态

受控工具、桌面批准和来源回执已实现。隔离端到端用例通过；匿名 HTTPS 真实访问已做基础冒烟。尚未完成真实模型端到端质量、速度与 Token 对照评测，不能据此宣称超过 Codex。

怎么用

  1. 在设置 → 执行引擎选择 Agent Deck Harness，保存并验证模型 API 配置。
  2. 新建工作，选择调研与文档，将工作区设为准备好的资料文件夹。目录必须只包含愿意提供给所选模型服务的材料；不要选整个个人目录。
  3. 需求里说明要读取的相对路径、你关心的问题和需要核验的公开 HTTPS 地址。确认计划后，Worker 在独立成果工作区执行；不会修改资料目录，也不会在其中初始化 Git。
  4. 网页访问发生前，检查地址，点击批准本轮读取或不访问。批准一个地址不会授权另一个地址；新一轮执行仍须重新批准。
  5. 写入 HTML 仍须通过受控文件操作批准。完成后到 Worker 的证据 → 读取过的来源检查回执，到产物查看报告，再人工验收。
  6. 把工作关联到个人项目后，只有已验收摘要才会参与下次背景复用；未验收草稿不会自动变成可信记忆。

架构与权限边界

工作目标 + 已授权背景 ↓

项目和记忆仍使用同一份账本。工作启动时固定来源目录与执行方式，模型不能通过提示词自行扩大授权。

只读资料目录 → reference_list / reference_read

宿主校验相对路径、符号链接、文件类型和大小。返回编号摘录、时间和整份读取文件的 SHA-256；原目录不是产物工作区。

单个公开 URL → 人工批准 → public_web_read

宿主检查 HTTPS 与公网 DNS，固定公网 IPv4 后建立连接。没有 Cookie、账号密码或浏览器登录状态；不跟随跳转、不执行脚本。

独立 Harness SDK：Executor → 新鲜 Auditor ↓

宿主提供受限工具，SDK 负责有预算的执行与独立只读复核。来源是引用数据，不是命令；回执说明读到什么，不证明来源真实或结论正确。

managed worktree → 文件批准 → HTML 草稿

原有写入边界不放宽；HTML 预览继续隔离脚本和网络。资料目录不被初始化、提交或自动导入。

真实事件 → 证据页 → 人工验收 → 下次复用

展示当前已加载的、属于此 Worker 的读取回执。验收不是自动步骤；来源和草稿不会自动写进用户记忆。

这一版支持与不支持什么

能力边界失败时怎么做
本地资料UTF-8 文本 / HTML / CSV / JSON；单文件最多 256 KiB；一次最多 501 行、约 4,500 字符摘录；工具 JSON 回执最多 5,800 字符导出较小的 UTF-8 文本；需要更多内容时按行继续读取
目录浏览只列一层、最多 80 项；隐藏文件、符号链接和明显的凭据文件排除指定允许的子目录；不会自动遍历整台电脑
公开网页HTTPS / 443、公开域名、公网 IPv4；无查询参数和片段；最多 256 KiB、15 秒；UTF-8 文本型内容提供规范地址；页面要求登录、跳转、压缩响应或 JS 渲染时会说明不支持，不偷偷换通道
来源证据URL / 相对路径、时间、范围、SHA-256、截断状态。哈希对应下载或文件字节，不是对事实正确性的担保继续读取、交叉核验；事件分页未加载的历史来源不在当前列表中
暂不支持全网搜索、PDF / Office 解析、登录网站、IPv6-only 站点、自动发布、后台长期授权。自有调研会话不开放 Shell / Git 工具，也不能写隐藏文件或版本元数据先手动导出资料或明确提供可支持的地址，不绕过站点访问限制；代码测试请使用代码开发模式

隐私与安全：不夸大保障

本地读取到的摘录会进入你配置的模型服务请求。文件名过滤和内容凭据检测只是额外防线，不能保证识别所有秘密；请先挑选和脱敏资料。路径、打开描述符和符号链接校验也不是针对恶意并发文件系统攻击的正式沙箱证明。

公开网页的服务器会看到请求来源 IP、路径和固定 User-Agent。批准仅覆盖当前轮次的同一 URL（含独立复核），不覆盖其他 URL、上传、登录或发布。来源里的提示注入可能影响模型判断，因此宿主权限校验不能交给模型；系统提示词只能增强边界，不能提供绝对防护。

现有已经创建的旧会话不会被悄悄追加资料访问权限。请用新工作体验这条自有 Harness 路径；外部 Agent 模式仍保持原有能力，不假装统一实现了这些宿主工具。
