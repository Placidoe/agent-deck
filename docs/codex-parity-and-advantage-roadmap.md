# Agent Deck：从基线持平到复杂任务领先

这份路线只接受可复现、可量化的收益。完成一项必须同时具备实现、自动验证和对照数据；界面上“看起来更智能”不算完成。

## 北极星指标

| 层级 | 质量目标 | 速度目标 | Token / 注意力目标 |
| --- | --- | --- | --- |
| 简单任务 | 与直接 Codex 相差不超过 5 分 | `T_green <= 1.10x`，硬上限 `1.35x` | 0 Planner、1 Worker、最多 1 次人工确认、Token `<= 1.15x` |
| 中等任务 | 至少高 5 分，或一次成功率高 10% | 快 15%，或不慢于基线且显著减少返工 | 人工活跃时间少 25%，Token/质量点更低 |
| 复杂任务 | 至少 2/3 个用例胜出，目标高 10 分 | `T_green` 快 25% | 人工活跃时间少 40%，可验证价值/1 万 Token 更高 |

## 执行原则

1. 按 `P0 -> P1 Direct -> P1 Complex -> P1 Token -> P2` 顺序推进。
2. 每完成一项都更新状态、测试和对照数据；没有同题证据不宣称超过 Codex。
3. 简单任务优先消灭控制面开销；复杂任务才用并行换取关键路径缩短和独立验证。
4. Provider Runtime 保持可插拔，但当前阶段不扩展 Provider，先把 Codex 路径做成可靠基准。
